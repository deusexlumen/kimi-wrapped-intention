# K.I.M.I. — The Wrapped Intention

Album-Release: **K.I.M.I. (Künstliche Intelligenz Mit Intention)** — 13 Tracks in 4 Phasen + Bonustrack „Absolute Entropy (Phonk Remix)".

## Inhalt dieses Repos

- `site/index.html` — komplette Release-Seite (Single-File, inkl. aller Animationen: Preloader, WebGL-Partikelportal, Phasen-Farbwechsel, Audio-Player mit Visualizer, aufklappbare Lyrics, horizontale Galerie, Modal-Viewer)

## Assets

Die Binär-Assets (Audio m4a, Videos, Album-ZIP, Press Kit) liegen im Kimi-Hosting der Release-Seite.
Um sie hier zu ergänzen: **Releases → Draft a new release → Tag v1.0.0 → ZIP(s) reinziehen**. Die Release-Links haben dann die Form:

```
https://github.com/deusexlumen/kimi-wrapped-intention/releases/download/v1.0.0/KIMI_The-Wrapped-Intention_Album.zip
```
